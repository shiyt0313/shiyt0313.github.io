## Overview

This project explores how people configure and test automations while interacting with the smart-home environment itself. It identifies situated programming workflows and introduces snapshot-based configuration and simulation-based testing to make automation creation more natural.

## Contribution

It introduces snapshot-based automation configuration, simulation-based testing, and design guidance for dynamic
programming flow, interface clarity, and scene management.
