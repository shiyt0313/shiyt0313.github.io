## Overview

ReactGenie is a development framework that translates combined voice-and-touch commands into executable programs. By resolving contextual references and composing application APIs, it enables rich, multi-step interactions while simplifying multimodal application development.

## Core Idea

A neural semantic parser translates multimodal commands into ReactGenieDSL, and the runtime composes primitives to
implement rich user interactions.
