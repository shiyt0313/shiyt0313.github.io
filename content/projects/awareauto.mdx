## Overview

AwareAuto translates contextual, multimodal user expressions into complex smart-home automations through LLM-based reasoning. It supports conditional branches, temporal constraints, and dynamic parameters while allowing users to review and refine generated rules.

## Core Idea

The system supports contextual, multimodal, and flexible user expression for dynamic parameters, multiple branches, and
temporal constraints that are difficult to express in traditional automation tools.
