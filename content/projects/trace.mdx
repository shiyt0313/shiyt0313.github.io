## Overview

TRACE combines ambient and wearable sensing with personalized routine information and LLM-based temporal reasoning to understand everyday activities in smart homes. It uses broader context to resolve ambiguous observations and produce more temporally coherent activity predictions.

## Core Idea

The framework progressively captures real-time activity features and structures their trajectories into long-term memory,
so the model can correct recognition results using a global historical perspective.
