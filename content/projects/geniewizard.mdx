## Overview

GenieWizard helps developers discover missing features in multimodal applications by simulating interactions from diverse user personas. It connects natural-language requests to missing APIs through LLM-based semantic parsing and program analysis, making feature discovery actionable within the development workflow.

## Core Idea

Its pipeline uses an LLM to generate possible user interactions, parse them into a domain-specific language, discover
missing functions, and surface those functions to the programmer.
